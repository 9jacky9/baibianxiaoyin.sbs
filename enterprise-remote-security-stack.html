用命令行测试代理是否生效：curl 与 ping 的基本用法

撰写：小樱使用手记 记录周期：2026-11-15 模块：命令行工具 读本 · 约 5 分钟

图形界面看不出问题时，命令行往往能给出更清楚的答案。几条常用命令就足够入门。

一、用 curl 指定代理

curl 可以通过参数指定本地代理地址，请求一个会返回出口地址的网页，对比开启与未开启代理时的结果，就能判断代理是否在工作。

二、查看耗时

使用格式化输出参数，可以分别看到域名解析、建立连接与首字节耗时。哪一项最长，一眼就能看出瓶颈在哪里。

三、ping 与路径追踪

  • ping 看延迟与丢包。
  • traceroute 或 tracert 看数据经过了哪些节点。
  • 注意 ping 使用的协议与网页不同，仅作参考。

四、验证 DNS

使用 nslookup 或 dig 查询域名解析结果，看是否与预期地区一致。

五、记录与对比

把命令与输出保存下来，改动设置前后各跑一次，便于对比。
